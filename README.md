# Сайт для клиента по аренде апартаментов

**🌐 [Сайт](isaakievskaya7.ru)**   
**📅 Проект выполнен в июле 2023**  
**📦 Добавлен на GitHub в марте 2026**

## О проекте
Коммерческий заказ от частного лица. Разработана главная страница со всеми необходимыми блоками. Реализована адаптивная верстка под все устройства

## Реализовано
*   Адаптивная сетка на Flexbox/Grid
*   Слайдеры на Swiper
*   Бургер-меню для мобильных устройств

## Почему код добавлен сейчас
В 2023 году при работе над проектом мы не использовали Git. Сейчас я привожу портфолио в порядок и добавляю ключевые коммерческие проекты на GitHub.

## Структура
*   `/css` — стили
*   `/js` — скрипты
*   `/images` — изображения
*   `/fonts` — шрифты
*   `index.html` — главная страница

## Технологии
HTML, CSS, JavaScript, Swiper
